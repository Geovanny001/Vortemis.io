# API de lectura `/v1`

- Fecha: 2026-11-16
- Rama: `feat/read-api`
- Base: `develop` en `4b2c80c`
- Objetivo: exponer el contrato de lectura por HTTP para un frontend externo.

## 1. Problema anterior

El motor era una librería en proceso. La única superficie de red era Streamlit. Un frontend externo no tenía forma de consultar nada: sin HTTP, sin tokens, sin CORS y sin contrato publicado.

## 2. Cambios

### Aplicación

`entrypoints/api.py`:

- FastAPI con `create_app(...)` y `app` a nivel de módulo.
- Dependencias: `HTTPBearer` para el token y una función que construye `FlowFilters` desde la query.
- CORS con allowlist explícita.
- OpenAPI automático en `/openapi.json` y `/docs`.

Endpoints:

| Método | Ruta | Auth |
|---|---|---|
| GET | `/v1/health` | no |
| POST | `/v1/auth/login` | no |
| POST | `/v1/auth/logout` | sí |
| GET | `/v1/auth/me` | sí |
| GET | `/v1/flows` | sí |
| GET | `/v1/stats/summary` | sí |
| GET | `/v1/stats/top-sources` | sí |
| GET | `/v1/stats/timeline` | sí |
| GET | `/v1/engine/metadata` | sí |

Límites: `limit` de 1 a 500, `bucket_seconds` de 10 a 86400, `threshold` de 0 a 1.

### Tokens

- Tabla `api_tokens`: `token_hash`, `operator_id`, `created_at`, `expires_at`, `revoked_at`.
- Migración `0002`.
- Token opaco de 32 bytes; en la base solo el SHA-256.
- TTL por entorno, 12 horas por defecto.
- Logout revoca; el estado del operador se resuelve uniendo con `soc_operators`, así un cambio de rol se aplica al instante.

### Sesiones

`application/sessions.py`: `OperatorSessionService`.

- `login` valida credenciales con `OperatorAuthPort` y emite token.
- `resolve` traduce token a identidad.
- `logout` revoca.

### Esquemas

`entrypoints/api_schemas.py`: modelos Pydantic para flujos, páginas, fuentes, timeline, metadata, resumen y salud.

### Configuración

- `ApiSettings.from_env()` con `VORTEMIS_CORS_ORIGINS` y `VORTEMIS_TOKEN_TTL_HOURS`.
- `.env.example` actualizado.

### Contrato

`docs/CONTRACTS.md` con endpoints, parámetros, respuestas, errores y reglas de versionado.

## 4. Decisiones

- La API vive en este repo; el frontend, en el suyo.
- Bearer token en lugar de cookie porque el origen es externo.
- Token opaco y hasheado en lugar de JWT: revocación real sin gestión de claves.
- El rol se lee de `soc_operators` en cada petición, no se congela en el token.
- `/v1` aditivo; un cambio incompatible abre `/v2`.
- `health` sin autenticación y sin datos.
- Rate limit de login reutiliza `LoginLimiter`; sigue siendo por proceso.
- Se revierte la decisión anterior de "sin API REST": ahora hay un adaptador HTTP, el motor sigue siendo el mismo.
